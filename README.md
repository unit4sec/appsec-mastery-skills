# AppSec Mastery — Implementation Skills

Ready-to-use **AI implementation skills** for the *Advanced Web & Mobile Application Security* course.

Each course topic ships one skill: a structured prompt you hand to your coding AI (Claude Code, Cursor, Copilot, etc.) so it implements that security control **correctly and securely** in *your* stack. The course teaches the theory (the risk and the why); these skills let you act on it.

The folders below mirror the course sections. Open a topic's `SKILL.md`, then paste it into your AI assistant (or drop the folder into `.claude/skills/`).
